\# Password Strength Checker 🔐



A simple Python project that checks the strength of a password based on common security criteria.



\## About



The Password Strength Checker analyzes a password using five basic criteria:



\* Password length

\* Uppercase letters

\* Lowercase letters

\* Numbers

\* Special characters



Based on the number of criteria satisfied, the password is classified as \*\*Weak\*\*, \*\*Medium\*\*, or \*\*Strong\*\*.



\## Features



\* Checks password length

\* Detects uppercase and lowercase letters

\* Detects numbers

\* Detects special characters

\* Provides a strength score out of 5

\* Gives suggestions for improving weak passwords

\* Runs directly from the Python terminal



\## Technologies Used



\* \*\*Python\*\*

\* \*\*Regular Expressions (`re`)\*\*
